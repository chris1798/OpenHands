GoogleChrome
Web 平台 / 前端最佳實踐

Chrome 團隊維護的現代 Web 指引源碼庫。核心問題很明確：AI 編碼代理的訓練資料裡塞滿舊寫法，於是它們會為一件現在已有原生 API 的事，生成一大堆 JS 與 polyfill。這個技能把策劃過的現代 Web 知識直接注入代理的上下文。

Stars★ 9,007 Forks749 本週+7,257 語言TypeScript 授權Apache-2.0 建立2026-01-27 官網

核心功能

  • 覆蓋 140 多項 CSS 與版面特性：:has()、@scope、@starting-style、view transitions、scroll-driven animations、field-sizing 等
  • 每條指引都經評估篩選，砍掉模型已經會的內容，保持 token 效率
  • 引導代理使用原生高效能 API，並附帶內建無障礙特性
  • 提倡負責任的降級方案，而不是無腦塞 polyfill 或舊版函式庫
  • 附有編寫、校準、評估內容的完整工具鏈

適用場景

AG-UI 是一個開放協議，用標準化的事件流把 AI 代理接到前端應用。任何接受 RunAgentInput 並串流回事件的 HTTP 端點就是一個 AG-UI 代理，不管你後端用 LangGraph、CrewAI、Mastra 還是自己寫的。

Stars★ 20,559 Forks2,113 本週+3,221 語言TypeScript 授權MIT 建立2025-05-07 官網

核心功能

  • 開放協議：不綁定特定代理框架或前端框架
  • 事件流式傳輸：文字增量、工具呼叫、狀態更新都以標準事件傳遞
  • 官方 CLI 一鍵腳手架：npx create-ag-ui-app，可選 CopilotKit 加 Next.js 或終端客戶端
  • 三十行內即可寫出一個可運作的代理伺服器與客戶端
